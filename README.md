# Quadratic equation solver

This tiny CLI program prompts the user for numeric values of a, b and c and then gives any existing real roots for the standard quadratic equation $ax^2 + bx + c = 0$.

### Why did I make this

Purely just to learn programming basics and git basics.


### Compilation command

```
g++ (cat compile_flags.txt) src/main.cpp -o build/QuadraticEquation
```
